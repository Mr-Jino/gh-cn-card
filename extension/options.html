GitHub 中文口语解读 → 去发现页（用中文找仓库）

点仓库页的「AI 解读」，它把 README 读成一份中文口语卡：先讲这玩意儿能干什么，再讲怎么跑，最后给你一句值不值得研究。

第一步 · 填三样东西（填一次就完事）

这串码告诉 DeepSeek「是你本人在用，费用记你账上」。它只存在你这台电脑的浏览器里，不会被传到任何别的地方。 保存时浏览器会弹一个框问「允不允许访问 api.deepseek.com」，必须点允许，不点就连不上。
没有它，GitHub 限制你每小时只能问 60 次，读十几个仓库就用完了。有它提到 5000 次，随便读。 怎么拿：打开 github.com/settings/tokens → Generate new token (classic) → 名字随便写、有效期随便选、下面所有勾选框一个都不用勾 → 点 Generate → 把 ghp_ 开头那串复制过来粘贴。

第二步 · 教它"你的口味"（这部分最重要）

AI 判断「值不值得」时，全靠这三框文字。打个比方：否决规则里写了"要 20G 显存的不推荐"，那它遇到吃显卡的项目就直接劝退你，而不是硬推荐。 所以照你平时说话的写法来，越具体越好。

例如：「批量处理 Excel 的」「能在 Windows 上当小服务跑的」。
例如：「要花钱订阅的」「数据必须传到别人云上的」「只有 3060 显卡跑不动的」。

第三步 · 和你的早报互通（可选）

你那个每天早上自动跑的 FRONTIER 早报（在 D:\FRONTIER 文件夹），和这个扩展各自记了一套"你的口味"。 这一步让两边共用同一套：早报的经验拿过来给扩展用；扩展攒的"没用"还回去给早报。

点「选择文件」，按住 Ctrl 一次选中两个文件：D:\FRONTIER\config.json 和 D:\FRONTIER\feedback.txt。 选完自动填进上面第二框并保存——早报这几天攒的判断经验，扩展立刻就会用。

在发现页勾「发群」的仓库、收藏里的仓库，可以一键推到 FRONTIER 的飞书群，和早报出现在同一个地方。 配置和早报共用一份：点上面的「选择文件」时，把 D:\FRONTIER\.env 也一起选上，两行自动填好； 或者自己用记事本打开 .env，把 FEISHU_WEBHOOK 和 FEISHU_SECRET 手动贴到下面。只存你本机浏览器里。

你在解读卡上点过「没用 / 跟我无关」的记录，点下面按钮会下载一个 frontier-feedback.txt。 用记事本打开 D:\FRONTIER\feedback.txt，把这些行粘贴到文件末尾保存就行，早报下次就不推同类的东西了。

已装好？以后改了代码怎么更新

  1. 双击项目文件夹里的 install-to-edge.bat（它把最新文件复制到位）。
  2. 打开 edge://extensions，在「GitHub 中文口语解读」卡片上点「重新加载」。
  3. 刷新 GitHub 页面，完成。

「清空解读缓存」只删读过的仓库记录（下次重新生成），不影响收藏和你的口味设置。
