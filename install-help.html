装到 Edge，还差最后两下点击

扩展已部署到纯英文路径 C:\Users\17704\AppData\Local\GhCnCardExt（Edge 对含中文的路径做"解压缩加载"会静默失败，之前卡住就是这个）。路径已复制到剪贴板，文件夹也已打开。

加载这个文件夹（已复制，文件选择框里 Ctrl+V 直接粘贴）：
C:\Users\17704\AppData\Local\GhCnCardExt
1

回到 Edge 扩展页，找「加载解压缩的扩展」按钮

就在 edge://extensions 页面左上方的工具栏里，「开发人员模式」开着才会出现。注意：拖文件夹进页面是装不上的，那个"拖放以安装"只认打包过的 .crx 文件，必须用这个按钮。

2

文件选择框里：地址栏粘贴 → 回车 → 选择文件夹

在弹出的文件夹选择框顶部的地址栏按 Ctrl+V 粘贴路径，回车，然后点右下角「选择文件夹」。这次是纯英文路径，不会静默失败了。

3

成功的标志

扩展页出现一张「GitHub 中文口语解读 0.1.0」的卡片。如果之前试出过一张带"错误"字样的旧卡片，先删掉它再重新加载。

3

弹出确认就点「添加扩展」

如果提示"此扩展程序并非来自 Microsoft Edge 加载项"，这是正常的——它就是本地开发的扩展，直接确认。

✓

装好后它会自动弹出设置页

填 API Key（默认 DeepSeek 配置，直接可用）和 GitHub Token，保存。然后去任意 GitHub 仓库页，仓库名旁边就有「AI 解读」。

以后更新怎么同步：我改了扩展代码后，你只要再双击一次 install-to-edge.bat（它会把最新代码镜像到 GhCnCardExt），然后在扩展页那张卡片上点「重新加载」即可，不用重新选文件夹。
如果「加载解压缩的扩展」按钮没出现：说明「开发人员模式」没开成功。扩展页左侧栏最底下有个开关，确认它是开的状态（绿色）。
